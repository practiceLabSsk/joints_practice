# 人体関節 3D ビューア

## GitHub Pagesで利用する場合

GitHubにリポジトリを作成しただけでは、Webサイトの配信は始まりません。GitHub側で **Settings → Pages** を開き、**Deploy from a branch**を選び、`index.html`があるブランチと`/(root)`を公開元に指定してください。公開完了後はPages設定に表示されるURLから利用できます。

この設定が済めば、Web上で使うためにローカルサーバーを立ち上げる必要はありません。HTMLのJS/CSS参照は、リポジトリ名を含むURLでも動く相対パスにしています。

GitHub Pagesのサイトはインターネット上に公開されます。リポジトリが非公開でも、Pagesの公開サイトは公開される場合があるため、実測関節データなどを含めないでください。[GitHub Pagesの作成手順](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## ローカルでプレビューする場合（任意）

`file://`で直接開くとESモジュールの読み込みが制限されるブラウザーがあります。ローカルで確認するときだけ、プロジェクトフォルダーをカレントディレクトリにして次を実行します。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで <http://127.0.0.1:8000/> を開きます。Three.js本体はプロジェクト内の`three.js`（r105）を使い、カメラ操作用のOrbitControlsは同じr105のファイルをjsDelivr CDNから読み込みます。そのため、カメラ操作の利用にはインターネット接続が必要です。

## 現在の開発範囲

STEP1〜8の表示・操作とデータ設計を実装しています。XYZ軸・XZ平面グリッド・照明・カメラ操作、12関節の球体と接続線、関節ごとの数値入力・スライダー、全関節の座標一覧を備えています。一覧から関節を選択でき、選択中の点を3D画面で強調表示します。画面幅に応じた配置、キーボードフォーカス表示、動きを抑える設定にも対応しています。2秒周期の歩行風デモを再生・一時停止し、タイムラインから位置を指定できます。関節IDは`AnkleLeft`、`AnkleRight`、`FootLeft`、`FootRight`、`HandLeft`、`HandRight`、`KneeLeft`、`KneeRight`、`Neck`、`spinebase`、`spinemid`、`spineshoulder`です。

## データと表示の分担

`jointData.js`は関節定義・接続定義・現在のポーズフレームを管理します。フレームは`{ time, joints: { [jointId]: { x, y, z } } }`の形で、座標変更とリセットはこのデータを更新します。`setCurrentPoseFrame()`は、選択した時刻のフレームを表示側へ渡す受け口です。

`demoData.js`は仮のキーフレームを補間し、同じポーズフレーム形式で時刻に対応する座標を作ります。`sceneRenderer.js`はThree.jsのシーン、関節メッシュ、接続線、カメラを管理し、ポーズフレームを受け取って表示します。`main.js`は入力欄・セレクター・一覧・デモ再生のイベントをまとめ、データ層と表示層をつなぎます。

座標は1単位を1m、Y軸を上、人物の前方を+Z、人物の左側を+Xとしています。接続線は首・首元・背中・腰の体幹から左右の手と膝へつなぎ、膝・足首・足を結ぶ簡易骨格です。将来のCSV形式は時間1列と12関節のXYZ座標36列の合計37列を想定しています。現在のデモはJavaScript内の合成データです。CSV読み込みとCSVデータの再生は未実装です。CSV列名・時刻の単位は、実データ形式が決まった時点で対応付けます。
