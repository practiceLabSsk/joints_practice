# 人体関節 3D ビューア

## 起動方法

プロジェクトフォルダーをカレントディレクトリにして、次のコマンドでPythonの静的サーバーを起動します。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで <http://127.0.0.1:8000/> を開きます。Three.js は jsDelivr CDN から読み込むため、表示にはインターネット接続が必要です。

## 現在の開発範囲

STEP6まで実装しています。XYZ軸・XZ平面グリッド・照明・カメラ操作に加えて、9関節の球体と接続線、関節ごとの数値入力・スライダー、全関節のXYZ座標一覧を表示します。座標の状態は`jointData.js`で管理し、3D表示と入力欄と座標一覧は同じデータから更新します。

座標は1単位を1m、Y軸を上、人物の前方を+Z、人物の左側を+Xとしています。関節間の接続は、首から左右の手・膝、膝から足首、足首から足へつなぐ簡易骨格です。肩・腰の関節点は仕様の9点に含まれないため省略しています。
